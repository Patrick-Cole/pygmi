Show Borehole Log
-----------------
This function displays the borehole log. It has the following aspects:

1. The locality and core number.
2. An image of the lithology of the log.
3. Information about the borehole.
4. Legend for the lithologies in the boreholes.
5. **BoreholeID** – The user can select the borehole to display using a dropdown list.
