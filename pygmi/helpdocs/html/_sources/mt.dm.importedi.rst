Import EDI Data
---------------
The Electrical Data Exchange (EDI) format is a standard format for storing MT data (Wight, 1991). This module imports EDI data into PyGMI. Note that more than one file can be selected at a time.

References
^^^^^^^^^^
 Wight, D. 1991. MT / EMAP Data Interchange Standard. The Society for Exploration Geophysicists, 104 pp.
