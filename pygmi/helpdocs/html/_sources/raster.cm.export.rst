Export Data
-----------
This exports the raster data into a variety of raster formats, including **ENVI**, **ER Mapper**, **GeoTIFF**, **Geosoft GXF** and **Surfer**. In most cases the GDAL library was used.

The user has the following options:

1. Select the locality, filename and format of the output file.
2. Select the bands to export by clicking on them. Bands highlighted in grey will be exported. A band can be deselected by clicking on it a second time.
3. The output bands can be sorted by band name.
