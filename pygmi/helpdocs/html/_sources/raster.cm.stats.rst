Basic Statistics
----------------
This shows statistics with respect to the output data. The statistics can be saved in a **CSV** file. They include:

* Minimum
* Maximum
* Mean
* Standard Deviation
* Median
* Median Absolute Deviation
* Number of samples
* Number of columns
* Number of rows
* Skewness
* Kurtosis
