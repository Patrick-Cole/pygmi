Model Creation and Editing
--------------------------

The **Model Creation and Editing** option allows the user to create a geological model based on observed potential field data or to create a synthetic model with no input data. The latter option is useful to test ideas or understand the responses of bodies with different petrophysical parameters. In the case of magnetic data, the response of a body at different locations on the Earth’s surface can be tested by selecting the magnetic field parameters (intensity, inclination and declination) at a specific locality.

All models are defined by their extents (length x width x depth) as well as the geophysical parameters which define each lithology. These are discussed below. The model extents dialog is the first to be seen when entering the modelling module.
