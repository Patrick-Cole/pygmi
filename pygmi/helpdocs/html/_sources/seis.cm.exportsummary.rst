Export Summary to CSV
---------------------
A summary of the events in the database can be exported to a **CSV**, Microsoft Excel (**XLSX**) or shapefile. The summary consists rows of events with the following information in the columns:

* Year
* Month
* Day
* Hour
* Minute
* Second
* Latitude
* Longitude
* Depth
* Ml
* Mw
* Md
* Mb
* Ms
* RMS
* LatitudeError
* LongitudeError
* DepthError
* Mo
* SourceRadius
* StressDrop
* StdDeviation
* Mercalli
* Agency
* Description
