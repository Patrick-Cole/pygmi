Import Seismic Data
-------------------
Imports SEISAN data stored in the **NORDIC** and NORDIC2** format, including **MACRO** files for macroseismic information. The figure below shows the full list of input formats.

.. figure:: _images/seisimp.png

   Formats of seismological data that can be imported.

For the **Simple event list in Excel (*.xlsx)** option, the spreadsheet must have columns with the following headings:

* Cyear or Year
* Month
* Day
* Hour
* Minute
* Second
* Latitude
* Longitude
* Depth
* Ml
* Mw
* Md
* Mb
* Ms
* Agency
