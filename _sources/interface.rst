User Interface Overview
=======================
The PyGMI interface uses a flow chart approach to perform tasks. The main interface groups tasks into categories within the menus. When a menu item is clicked, it appears as a flow chart element on the main interface. In this manual these items are referred to as modules. The main interface consists of the following elements:

1. Main menu.
2. Module selected from the menu. 

  a. Double-clicking on a module brings up a relevant dialog box. When the options in the dialog box have been accepted, the module runs.
  b. The module turns to green after it has run.
  c. Right-clicking on the module brings up a context menu that allows for the display of any data and results associated with that task.

3. **Line pointer** to connect two modules on the flow chart. 
4. Blue-coloured modules still need to be activated.
5. Red-coloured modules are in the process of running.
6. Dataset information. This shows the data in the specific module that the user clicked on.
7. Process log turns red when a process is running. Once it is complete it will turn white again.
8. Clicking on the **Play** icon on the menu bar runs all tasks in sequence.
