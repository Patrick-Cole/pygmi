Geochemistry and Lithology Processing
-------------------------------------
This tool allows for the creation of a series of geochemical products. It requires as input some point geochemistry data. Once the module is activated, a polygon lithology shapefile can be loaded. The user has the following options:

1. **Load Lithology File** - this is a shapefile containing lithologies.
2. **Plot Type** - This can be one of the following:

  * **Geochemistry**
  * **Original Lithology**
  * **Lithology Assigned to Geochemistry**
  * **Statistics Graphs**
  
3. **Channel** - Geochemistry channel. Only available for **Geochemistry** and **Statistics Graphs**
4. **Style** - Only available for **Geochemistry**. Can be one of the following:

  * **Normal**
  * **Group using Standard Deviations above Mean (0)**
  * **Group by Quartile**
  * **Group into K-Means Classes**

5. **Statistics** - Only available for **Statistics Graphs**. Can be one of the following:

  * **Line Plot with Table**
  * **Bar Plot**
  * **Box and Whisker Plot**
  * **Violin Plot**
