3D Model Display
----------------
The 3D model display menu provides a viewer for 3D voxel data. 

.. figure:: _images/pfmod3d.png

   3D Model Display interface.

The interface has the following aspects: 

1. Model display window - The model can be rotated using the left and right click mouse buttons. Use the mouse wheel to zoom in and out of the model.
2. Vertical slider - The slider adjusts the vertical exaggeration of the model.
3. Select lithologies to display - By default all lithologies are selected. Click on a lithology to toggle it on and off. 
4. Light Type - This can be **Headlight** (no shadows) or **Camera light** (shadows controlled by **Light Position**)
5. **Light Position** - The position of a light source can be changed to control shadow effects on the model. Only available in **Camera light** mode.
6. **Reset Light** - resets the light position for **Camera light** mode.
7. **Smooth Model** - Apply smoothing to the model, showing a more aesthetically pleasing version.
8. **Save to Image File (JPG or PNG)** - The viewer provides a means to save an image of the model to a **JPG** or **PNG** file format.
9. **Refresh Model** - Used to update the viewer while actively modelling.
