Import Borehole Data
--------------------
The CGS stores borehole data in two Microsoft Excel files:

* Header file with the following columns: Seqno, Farmname, Farmno, Regdist, Companyno, Boreholeid, Depth from, Depth to, Drill date, Inclination, Azimuth, Map, Latitude, Longitude, Elevation, Lox, Loy, Locunc, Declat, Declon, Commodity, Commodity2, Commodity3, Commodity4, Company.
* Lithology file with columns: Seqno, Farmname, Farmno, Regdist, Companyno, Boreholeid, Map, Depth from, Depth to, Lithology status, Lithology, Stratigraphy, Rank, Lithology description.

When selecting **Import Borehole Data** the user will be requested to select the two MS Excel files. It will first ask for the lithology file and then the header file (see the description at the top of the **File Open** dialog box.
