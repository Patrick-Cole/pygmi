Display Voxel Data
------------------
This module displays voxel data in 3D. Voxels are displayed in a volume with an interactable slice, changed using the mouse. There are a number of options:

1. **Slice in Opaque Volume** - Makes the volume being sliced opaque
2. **Save to Image File (JPG or PNG)** - Saves an image to disk.
