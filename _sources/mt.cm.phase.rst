Plot Phase Tensor
-----------------
This displays the MT phase tensor map. It has the following options:

1. **Frequency** - phase tensor map frequency.
2. **Ellipse colour by** - parameter to use for colouring ellipses. It can be skew, phimin or phimax.
3. **Ellipse scale factor** - Scale of ellipses.
4. **Plot real tipper** - check this to plot real tipper values.
5. **Plot imaginary tipper** - check this to plot imaginary tipper values.
6. **Export current frequency to shapefiles**
7. Standard image display setting that allows the user to zoom into specific areas of the image, move the zoomed in area around, return to the full image, save the image, etc.
