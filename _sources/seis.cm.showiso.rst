Show Isoseismic Plots
---------------------
This allows for the display of Isoseismic plots after a SEISAN macro file has been imported. The are two different products:

1. **Convex Hull Method** - This uses convex hulls to calculate the plot. A convex hull is calculated around each group of intensities.
2. **Standard Contours** - standard contouring approach.

Results can also be saved to a shape file.
